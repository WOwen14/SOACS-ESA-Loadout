# Changelog

## 0.1.0 — 2026-07-13

- Added VS2019-compatible WPF application targeting .NET Framework 4.8.
- Added offline folder scanning and automatic category detection.
- Added operator category override for unrecognized folders.
- Added editable XML deployment profiles with automatic `.bak` backup.
- Added visible build progress, cancellation, activity log, file counts, and sizes.
- Added expanded-folder and ZIP output.
- Added package XML manifest and SHA-256 checksums.
- Added self-elevating PowerShell deployment with typed approval.
- Added preview-only deployment mode.
- Added overwritten-file backup, post-copy verification, receipt, and rollback.
- Added safe Lab / Staging profile and operational path placeholders.
